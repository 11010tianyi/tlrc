# aitldr

**Official TLDR first. AI only fills gaps.**

A [tldr](https://github.com/tldr-pages/tldr) client — when the official page exists, use it; when it doesn't, AI generates one.

[![license](https://img.shields.io/github/license/11010tianyi/tlrc?color=b4befe&labelColor=363a4f)](/LICENSE)

[中文文档](README_zh.md)

</div>

## How It Works

```
tldr <command>
  ├─ Official page found?        → Show it (identical to upstream tlrc)
  ├─ Bio community page found?   → Show it [Bioinformatics Community Page]
  ├─ AI cache found?             → Show it [AI Generated Page (cached)]
  └─ None found?                 → AI generates one [AI Generated Page]
```

The official tldr experience is never affected. AI is a fallback — nothing more.

## Features

- **AI Page Generation** — DeepSeek, OpenAI, or Ollama generates tldr pages for commands not in the official repository.
- **Natural Language Queries** — Ask in plain language (including Chinese) and get the corresponding shell command.
- **Bioinformatics Community Pages** — 40+ bio tools and 25+ bio formats from [bioinformatics-command](https://github.com/11010tianyi/bioinformatics-command), checked before AI.
- **Smart Caching** — Pages, natural language results, and explanations are all cached locally. No wasted tokens.
- **Command Explanation** — `--explain` gets AI-generated explanations, also cached.
- **Destructive Command Warnings** — Flags dangerous commands like `rm -rf`.
- **Offline AI** — `--offline` skips cache updates but AI generation still works.

## Installation

```shell
git clone https://github.com/11010tianyi/tlrc.git
cd tlrc
cargo build --release
```

The binary is at `target/release/tldr`. Move it to your PATH:

```shell
cp target/release/tldr /usr/local/bin/
```

## Quick Start

**1. Initialize:**

```shell
tldr --init
```

Edit `~/.aitldr/config.toml` to set your API key:

```toml
[deepseek]
api_key = "your-api-key-here"

# Or use an environment variable:
# api_key = "env:DEEPSEEK_API_KEY"
```

**2. Use:**

```shell
tldr tar              # Official page — works exactly like upstream
tldr stringtie        # Bio community page — no token needed
tldr codesign         # AI generated — only when no other source exists
tldr "查找大文件"      # Natural language → shell command
tldr "sort by size" -e # Command + AI explanation
```

## Usage

```
tldr [OPTIONS] [PAGE]...

Standard options:
  -u, --update                    Update cache + bio community pages
  -l, --list                      List pages in current platform
  -a, --list-all                  List all pages
  -s, --search <KEYWORD>          Search pages
  -p, --platform <PLATFORM>       Specify platform (linux, osx, windows, etc.)
  -L, --language <LANGUAGE_CODE>  Specify language
  -o, --offline                   Skip cache updates (AI still works)
  -R, --raw                       Raw Markdown output
  -q, --quiet                     Suppress status messages

AI options:
  -e, --explain                   Explain command with AI (cached)
  -r, --refresh                   Delete AI + explanation cache, regenerate
  -m, --model <MODEL>             Override provider (deepseek, openai, ollama)
      --init                      Initialize ~/.aitldr/config.toml
      --ai-status                 Show AI configuration

Page lookup order: official cache → bio community pages → AI cache → AI generation.
```

## Page Lookup in Detail

When you run `tldr <command>`, the lookup order is:

1. **Official page** — Local tldr cache. Identical to upstream tlrc.
2. **Bio community page** — `~/.aitldr/bio-command/` for bio tools (samtools, gatk, stringtie, etc.).
3. **Bio format page** — `~/.aitldr/bio-format/` for bio formats (bam, vcf, fasta, etc.).
4. **AI cache** — `~/.aitldr/ai/` for previously generated pages.
5. **AI generation** — Only if the command exists on your system (prevents hallucination). `--offline` skips this check.

Bio pages are auto-downloaded on first use. `--update` refreshes them.

### Offline Mode

`--offline` only skips cache updates. Everything else still works:

```shell
tldr --offline stringtie           # Bio community page or AI cache
tldr --offline "查找大文件" -e      # NL query + AI explanation
tldr --offline codesign            # AI generates (skips command_exists check)
```

## Caching

All AI content is cached to avoid redundant API calls:

| Cache | Path | Purpose |
|-------|------|---------|
| Page | `~/.aitldr/ai/{command}.md` | AI-generated tldr pages |
| NL | `~/.aitldr/nl/{query}.txt` | Natural language → command |
| Explanation | `~/.aitldr/explain/{command}.txt` | AI command explanations |
| Bio-command | `~/.aitldr/bio-command/*.md` | Bio tool pages |
| Bio-format | `~/.aitldr/bio-format/*.md` | Bio format pages |

```shell
tldr --refresh tar    # Delete AI page + explanation cache, regenerate
tldr --update         # Refresh official pages + bio community pages
```

## AI Configuration

Config file: `~/.aitldr/config.toml` (generated by `tldr --init`).

```toml
[general]
explain_default = false    # Auto-explain in NL mode
cache_enabled = true       # Cache AI results (recommended)
language = "zh"            # "en" for English, "zh" for Chinese

[model]
provider = "deepseek"      # "deepseek", "openai", or "ollama"
model = "deepseek-chat"

[deepseek]
api_key = "env:DEEPSEEK_API_KEY"   # Or paste your key directly

[openai]
api_key = "env:OPENAI_API_KEY"

[ollama]
endpoint = "http://localhost:11434"
model = "qwen2:7b"
```

### Check Configuration

```shell
tldr --ai-status
```

### Environment Variables

Use the `env:` prefix in config to reference environment variables:

```shell
export DEEPSEEK_API_KEY="sk-..."
```

## Destructive Command Warnings

```
tldr "删除所有文件"

rm -rf /path/to/dir

WARNING: Destructive command! This operation may cause irreversible data loss.
```

## Standard tlrc Configuration

aitldr inherits all [upstream tlrc](https://github.com/tldr-pages/tlrc) configuration options. Run `tldr --config-path` to find your config file, or `tldr --gen-config` to print defaults.

For a [tldr-python-client](https://github.com/tldr-pages/tldr-python-client)-like style:

```toml
[output]
show_hyphens = true
compact = true

[style]
title.color = "default"
title.bold = true
description.color = "default"
bullet.color = "green"
example.color = "red"
placeholder.color = "default"
```
